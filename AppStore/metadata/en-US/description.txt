Ayami is a quiet, read-only Markdown viewer for Mac, iPhone, and iPad. Open your documents as clean, structured pages. This Mac edition requires an Apple silicon Mac running macOS 26 or later. Intel Macs are not supported.

Open .md files and read them as clean, structured documents without switching into an editor. Each document opens in its own window by default, with an option to add files as native macOS tabs. A single command arranges open documents side by side for comparison.

LIVE RELOAD
Keep using your preferred editor. Ayami detects ordinary saves and atomic file replacements, then refreshes the reading window automatically.

ACTIVE CHAPTER OUTLINE
The optional Contents sidebar lists headings and highlights the section currently being read. Select a heading to move directly to it.

MERMAID, OFFLINE
Mermaid fenced code blocks render locally with the runtime included in the app. There is no setup, package installation, CDN, account, or cloud service.

NATIVE MAC EXPERIENCE
Use Command-O to open a file in a new window, Command-Option-O to open one in a new tab, and Command-W to close the active tab or window. Window size is restored across launches, and appearance follows the system.

PRINT AND PDF
Open an A4 or Letter PDF preview from Document Actions or Command-P, then save or print Japanese text, tables, and Mermaid diagrams. Invalid diagrams or rendering failures show a warning and readable source instead. Output uses its own layout; it does not reproduce images or the screen layout exactly.

FINDER QUICK LOOK
Select a Markdown file in Finder and press Space to preview its contents and Mermaid diagrams in a continuous scrolling view. Page breaks apply to printing and PDF export. If another Markdown Quick Look extension is installed, check the enabled extensions in System Settings.

READ AT YOUR OWN SIZE
Adjust text size from 80% to 160% with a slider in Reading Settings. Your preference is remembered and applies immediately to all open documents, including Mermaid diagrams.

ON-DEVICE DOCUMENT HIGHLIGHTS (PROTOTYPE)
When Apple Intelligence is available, generate highlights of the open document in Japanese or English using Apple's on-device model only. Documents are not uploaded or written back to the original file. Apple Intelligence must be enabled, its model ready, and the language supported. Availability and generation can fail depending on the environment. AI output may be incorrect; check the original document. Reading, printing, and PDF export remain available without AI.

Document viewing and output are read-only. No editor, ads, tracking, or account registration.
