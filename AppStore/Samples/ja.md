# Markdownを、静かに読む

いつもの文書を、読みやすい一枚に。

## 考えるための、小さな余白

メモも、プロジェクトの手引きも、思いつきも。**編集は、いつもの道具で。** あやみは「読む」を整えます。

| 自分に合わせる | 読むことに集中 |
| --- | --- |
| 文字サイズを調整 | 読み取り専用 |
| 見出しからすぐ移動 | アカウント不要 |

## 考えを、図でたどる

```mermaid
flowchart LR
  A[読む] --> B[わかる]
  B --> C[つくる]
```

Mermaidの図も**オフライン**で。設定も、クラウドへの送信も不要です。

## 細部まで、すっきりと

```swift
let idea = "静かに読める場所"
print(idea)
```

読みたい速さで、読みやすい大きさで。
