# Read Markdown quietly

Ayami turns local `.md` and `.markdown` files into readable documents.
Version 1.3 supports macOS 26+ and iOS/iPadOS 18+. It is a viewer, not an editor:
your files remain under your control. GitHub source releases and App Store
availability are separate; check the [App Store](https://apps.apple.com/app/id6794576868)
for the currently available version.

## Highlights

- Native SwiftUI interface for Mac, iPhone and iPad
- Live reload after external saves on Mac, including atomic file replacements
- A chapter outline that follows the section you are reading
- Individual document windows with optional native tabs and side-by-side
  arrangement on Mac; system-managed multiple windows on iPad
- Offline Mermaid diagrams with no setup or CDN
- Native printing and PDF output on Mac
- A saved text-size slider for comfortable reading
- Layouts adapted to compact and regular windows, with iPhone Duo simulator validation
- Light and dark appearances that follow the system
- No account, analytics, advertising, or cloud service
