# Ayami / あやみ 1.3

読み取り専用 Markdown ビューアー「あやみ」の 1.3 ソースリリースです。
アプリのバージョンは **1.3（ビルド18）**。macOS 26+、iOS/iPadOS 18+ を対象にします。
GitHub 上の公開と App Store での提供状況は別です。アプリの入手可否は
[App Store](https://apps.apple.com/app/id6794576868) を確認してください。

## 変更点

- MD Viewer から「あやみ / Ayami」へ改名し、リポジトリ・プロジェクト構成も統一。
- iPhone・iPad に対応。「ファイル」から Markdown を読み取り専用で開けます。
- 表示設定へ 80〜160% の文字サイズスライダーを追加。設定は端末内に保存します。
- 明るい生成り・杏色の背景と、見台をモチーフにした新アイコンを採用。
- Mermaid を 12.2.0 へ更新し、オフライン描画を維持。
- Duo の開閉・画面変更で文書バーが二重表示される問題を修正。
- Mac のネイティブタブ、左右配置、Live Reload、印刷・PDF 出力は維持。
- 公開文書を現行仕様へ整理し、古い計画や重複した検証表を正本への参照へ置き換え。

## 検証

Xcode 27.1 で Mac、iPhone、iPad、Duo 内外画面を検証しました。
テスト件数・製品版の画面確認と制限は
[検証記録](https://github.com/hshimomura/ayami/blob/v1.3/docs/iphone-duo-validation-1.3.md)、
採用依存は [依存監査](https://github.com/hshimomura/ayami/blob/v1.3/docs/dependency-audit-1.3.md) を参照してください。

製品コードの検証基準は
[`3a2271e`](https://github.com/hshimomura/ayami/commit/3a2271ee7cbb757f61ad917d2bc1124e70b2da25)。
本タグにはその後の公開文書整備を含みます。文書整備に伴うストア用ビルドの再送信は行いません。

## 制限

- Duo を含む iOS 検証はシミュレーターです。実機、iOS 18 上の実行、Files/iCloud Drive
  の各プロバイダー、最大 Dynamic Type・VoiceOver の追加確認は別途必要です。
- iOS の Mac 型タブ、独自のファイル監視、印刷・PDF 出力はありません。
- 相対パス画像と Find は未実装。Mac 印刷の Mermaid はソース表示になります。

## 公開物

`ayami-1.3-source.tar.gz` はタグのソースアーカイブ、`SHA256SUMS` はそのチェックサムです。
GitHub 自動生成の Source code アーカイブとはファイル名・圧縮形式が異なります。
App Store 用の署名済み pkg/ipa、プロビジョニング、証明書、非公開の審査情報は添付しません。

```sh
shasum -a 256 -c SHA256SUMS
```
