# Ayami / あやみ 1.4

Mac・iPhone・iPad向けの印刷・PDF出力を共通化し、Mermaidを図として出力できるようにしました。
アプリのバージョンは **1.4（ビルド20）**。GitHubのソース公開とストアでの提供状況は別です。
アプリの入手可否は[App Store](https://apps.apple.com/app/id6794576868)を確認してください。

## 主な変更

- A4・LetterのPDFプレビュー、保存、システムの印刷画面に対応。
- 本文・表は選択可能な文字として、Mermaidはベクター図としてPDFへ出力。
- MacのFinder Quick LookでMarkdown本文・表・Mermaid図を連続表示。改ページ・ページ番号は印刷／PDF保存に限定。
- MacはApple silicon専用。Intel Macは対象外。
- Apple Intelligenceの端末内モデルによる「文書の要点（試作）」を追加。

## AIの条件と制限

macOS・iOS・iPadOS 26以降で、Apple Intelligence対応端末・有効化・モデル準備・対応言語が必要です。
明示的に生成を開始した場合だけ開いている文書を処理し、クラウドへのフォールバックや元文書への書き戻しは行いません。
利用不可・生成失敗を表示する場合があります。誤りがあり得るため、結果は原文と照合してください。
AIを利用できなくても閲覧・印刷・PDF保存は使えます。

Macでは実生成成功を確認しました。iPhoneシミュレーターでは実生成が失敗し、iPad/Duoの実生成は未確認です。
このためAIは試作機能として提供し、全プラットフォームでの生成成功を保証しません。

## 出力とQuick Lookの制限

無効なMermaidや描画タイムアウト時には警告とソースを出力します。
画像の読み込みや画面のHTML/CSSレイアウトの完全再現には対応しません。
Quick LookはほかのMarkdown拡張との共存・登録状態に影響される場合があります。

## 検証と文書整備

ビルド20ではMacの39件の回帰テストの実行結果が成功しました（任意のAI実生成1件はskip）。
印刷パネル・PDF実保存・Finderの連続HTMLとMermaid SVG表示も確認しました。
iPhoneシミュレーターではPDF／SVG生成とビルド番号の対象10件が成功しました。
Macの実AI生成、iPhone・iPad・Duoの印刷画面とPDF実保存は、ビルド19での検証履歴を参照してください。
紙への印刷・iOS実機は自動検証の対象外です。Duoの1.4新規画面での内外画面切替は未確認です。
環境・件数・過去の失敗と成功の区別は
[1.4検証記録](https://github.com/hshimomura/ayami/blob/v1.4/docs/validation-1.4.md)を参照してください。

README、設計、実装、サポート、プライバシーを1.4へ統一し、1.3の仕様・検証記録は履歴へ分離しました。
固定依存は1.3から変更していません。本タグと添付ソースをビルド20の製品コードへ更新しました。
リポジトリ専用のApp Store Connect skillと認証ヘルパーも追加し、申請操作は原則APIを使う手順を整えました。

## 公開物

`ayami-1.4-source.tar.gz`はタグのソースアーカイブ、`SHA256SUMS`はそのSHA-256です。
GitHub自動生成のSource codeアーカイブとはファイル名・圧縮形式が異なります。
署名済みpkg/ipa、ビルド出力、証明書・プロビジョニング、非公開の審査情報は添付しません。

```sh
shasum -a 256 -c SHA256SUMS
```
