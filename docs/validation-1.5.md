# あやみ 1.5（21）開発・検証記録

2026年10月26日、`codex/v1.5`で開発。対象はREADME・設計書・AI生成Markdownを読む
Macのエンジニア。開発版の機能と検証を記録するもので、ストアでの提供開始を意味しない。

## 実装した機能

| 機能 | 操作・振る舞い |
| --- | --- |
| 一時的な蛍光ペン | 文章を選択し、ツールバーの蛍光ペン、またはMacの⌘⇧Hでピンクにマーク。マークをクリックして文書の操作メニューから個別解除、または一括解除 |
| 文書内検索 | 虫眼鏡、Macの⌘F。一致を色で示し、件数・前後移動・⌘G／⌘⇧Gに対応。日本語、書式をまたぐ文章、コード、表を検索 |
| 相対画像・リンク | アプリ内で相対画像、関連するMarkdown・HTML・テキスト・ソース、見出しアンカーを開く。必要な場合だけプロジェクトフォルダーを選択してアクセスを許可 |
| リンクの表示先 | Macの文書リンクは新しいタブが初期値。「閲覧設定」で新しいウィンドウを選択でき、端末内に保持 |
| HTMLとテキスト | Markdown内HTMLと`.html`を表示。`.txt`・`.json`・`.c`などは原文として開き、検索・マーク・コピーに対応 |
| コードコピー | コードの囲み記号を含めず、ブロックの内容をクリップボードへコピー。Prismで色分けを維持 |
| Live Reload | Macの外部保存・原子的なファイル置換を監視し、読んでいた段落と画面内の位置を復元 |
| Mermaid拡大 | 図の「図を拡大」から25〜400%へ拡大・縮小、スクロール、「全体を表示」、完了／Escapeで閉じる |
| 導入 | Macのようこそ画面、日英の公開技術文書サンプル、閲覧・フォルダー許可・Finder Quick Lookの案内 |

マークは文書ごとのメモリーだけに置く。文書を閉じると消え、保存確認は出さない。
Markdown、PDF、UserDefaults、ログへ書き出さない。別の文書への移動中やレイアウト変更では
開いたままの文書のマークを保持する。外部変更後も、元の文章を一意に照合できる場合に保持する。
特定できない場合は解除して案内する。

## 実装上の判断

検索・選択・複数箇所のマークを同じ本文に対して扱うため、主な閲覧面を非永続の
`WKWebView`へ移した。SwiftUIの目次、設定、文書管理、ステータス、印刷・PDF・AIは維持する。
`ReaderSession`が文書ごとにページを保持し、compact/regularの切り替えでも使い直す。
弱参照のメッセージ中継でページ・Coordinator・セッションの循環参照を避ける。

- `ReaderWebView.swift`: SwiftUIとWebKitの橋渡し、ネイティブのコピー、状態・遷移。
- `ReaderResources.swift`: 同梱資産、画像の取得、フォルダー境界と実パスの検証。
- `Resources/Reader/reader.js`: 検索、一時マーク、段落位置、画像、コード、図の拡大。
- `ReaderGuideView.swift`: ようこそ画面、サンプル、案内、iOSの関連文書画面。

文書内HTMLとHTML文書はDOMPurifyと許可リストで処理し、表・強調・折りたたみと
限定したインラインCSSを表示する。文書スクリプト・フォーム・イベント属性は除去する。
文書のIDに接頭辞を付け、操作用属性を分離する。同梱スクリプトだけを読み込み、
CSPで外部通信を拒否する。画像取得は文書のフォルダー、明示的に選んだプロジェクト、
同梱サンプルに限定する。`realpath`で範囲外のシンボリックリンクを拒否する。
フォルダーの許可はアプリのセッション内だけに保持し、ブックマークとして保存しない。
